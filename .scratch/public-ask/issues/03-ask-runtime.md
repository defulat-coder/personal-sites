# 实现受限的公开资料问答运行时

- Type: server feature
- Status: ready
- Blocked by: 01-public-search-schema

## Outcome

`POST /api/ask` 能对匿名访客请求执行范围受限的全文检索，并通过 Pi/Kimi 流式返回只基于已召回来源的中文回答与受控引用。每个浏览器指纹会话使用独立的文件 Pi 会话，而不是服务器内存会话表。

## Scope

- 定义并校验问答请求：问题、资料范围和浏览器生成的会话标识；限制输入长度和轮次，拒绝非法范围。前端不得上送或记录原始指纹组成信息。
- 用仅服务端保存的 `ASK_SESSION_SECRET` 对浏览器会话标识派生 Pi 会话 ID；原始标识不得出现在 JSONL、日志、数据库、URL 或响应中，缺少密钥时以明确配置错误失败。
- 实现 `AskRateLimiter` 抽象及本地内存实现：按 IP 在 10 分钟内允许 50 次，超限返回明确 `429`；测试可注入时钟与来源 IP。
- 通过服务端全文搜索契约取得候选资料；来源不足时直接给出证据不足结果，不让模型用常识补全。
- 使用浏览器会话标识的不可逆服务端派生值作为 Pi 会话 ID，并以 `SessionManager.create()` / `SessionManager.open()` 在 `var/ask-sessions/` 管理 JSONL 文件；不缓存会话实例。会话文件按可配置保留期（默认 24 小时无活动）清理，目录权限限制为当前用户可读写。
- 对同一会话的并发请求进行串行化，避免 JSONL 写入和上下文分叉互相覆盖；客户端不能猜测或直接读取会话文件。
- 设置空工具集、关闭技能/资源发现、关闭思考输出；Pi 只能看到恢复的会话上下文与服务器提供的来源，不能把会话文件作为可浏览资源访问。
- 仅将服务器选择的公开资料和必要的最近对话上下文交给 Pi；模型不能读取数据库、文件、GitHub 或调用任何工具。
- 定义稳定 SSE 事件：来源清单先行、文本增量、完成、受控错误；回答正文和提问正文不写入日志或数据库，只采集匿名运行指标。

## Acceptance

- 每个成功答案均附带实际检索来源；无结果或证据不足时明确说明，且无虚构引用。
- 连续追问和同一浏览器会话的重载可恢复同一 Pi 上下文；不存在会话标识、会话已过期或文件被清理时安全地开启新会话。
- 测试覆盖范围筛选、中文命中、无结果、Kimi 配置缺失/失败、限流、工具禁用、SSE 完整性和临时会话清理。
- 测试证明会话 JSONL 位于 Git 忽略和安全规则阻断的 `var/` 下，且浏览器或公开 Supabase 调用无法取得 Kimi 密钥、service-role key、私有资料或其他访客的问答正文。

## Notes

Pi 原生持久化格式为 JSONL，不是单一 JSON 文档；本票据复用该格式而非自行实现第二套会话序列化。它继续使用现有 Kimi/Pi 生成配置；不引入 Embedding Provider、向量召回或通用 Agent 工具。
