# Design Brief: 每日动态流（列表 + 详情） @ 2026-08-14

## User Job

快速扫过去 24 小时（最多 7 天）的 AI 行业动态，判断哪几条值得点开；点开后在站内读完摘要与推荐理由，需要时跳转第三方原文。

## Primary Object

列表：单条动态的标题。详情：导读正文。

## Primary Action

列表：点开一条动态。详情：读完导读（其次才是跳转原文）。

## Information Hierarchy

列表：
1. 日期分组（8月14日 · 星期五 · N 条）
2. 条目标题
3. 摘要
4. 元信息（时间 · 来源 · 分类 · 精选）

详情：
1. 标题（全站唯一 display 级 h1）
2. 导读
3. 推荐理由（仅精选条目有）
4. 元信息与原文出口

## Density Target

列表 moderate 偏紧——与每日关注流同密度，滚动扫读；详情 spacious——单栏阅读流。

## Reference Feeling

Feels closer to:
- 站内每日关注流（已批准的参考切片）——1px 分隔线连续流、hover 只动文字与箭头
- Ample Studio 式克制——层级靠字号/粗细/留白，不靠容器

Does not feel like:
- 当前实现的时间轴轨道 + 圆点 + 左侧时刻列——另一套视觉语言，与全站"连续分隔线流"冲突
- 资讯聚合站的徽章/评分墙——每行右侧的 AI 评分与 pill 徽章制造碎噪的右缘

## Remove / Quiet / Sharpen

- Remove: 时间轴竖线与圆点；行内「推荐理由」块（详情页已有）；行内「AI 评分」（上游的判断，不是本站的判断，且制造参差的右缘）；详情的 pill 徽章行；详情顶栏右侧动作堆叠。
- Quiet: 「精选」从 pill 徽章降级为元信息里的一个 quiet 文本标记；分类筛选 chips 保持既有 tag 组件。
- Sharpen: 条目标题升级到契约的 stream headline 档（570 / clamp(1.05rem,1.5vw,1.35rem) / balance）；详情 h1 使用契约 display 档（全站唯一允许处）；原文出口用契约 external-link 组件（ink 实心 pill）。

## Non-Negotiables From The Contract

- 平面、细分割线、连续流；不用卡片、阴影、装饰背景。
- 单色体系；行 hover 只改文字颜色与箭头位移。
- 详情页复用同一身份轨；只有详情 h1 可用 display 字号。
- 动效需 prefers-reduced-motion 静态路径；加载骨架与空态已存在，保持。
